ENIGMA — SECTION 03 · PORTFOLIO IMAGES
======================================

Drop your work here, named:

    01.jpg  02.jpg  ...  08.jpg

They appear automatically — no code changes needed.

The GEOMETRY DOES NOT MOVE when you add them. Each slot's world size
(and therefore its aspect ratio, crop and on-screen dimensions) is fixed
in the PROJECTS array at the top of folio.js, measured from the reference:

    01 The Milan Edit    447 x 634   (the hero, red)
    02 Black Room        363 x 567
    03 Red Code          306 x 567   (red)
    04 Backstage         330 x 567
    05 Behind the Scenes 300 x 540
    06 Night Protocol    352 x 567
    07 Atelier           318 x 545   (red)
    08 (text card)       372 x 567

Images are cover-cropped to those boxes; tune the framing per slot with
the `op` field (CSS object-position).

The red/dark wash on the accent slots is a PLACEHOLDER treatment only.
It is dropped the moment a real photograph loads, so your imagery is
never tinted.
